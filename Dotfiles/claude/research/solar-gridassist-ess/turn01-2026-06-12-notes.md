## Findings
- "GridAssist"/"grid assist" ≈ generic hybrid-inverter marketing term for *simultaneous* inverter+grid operation (grid-parallel blending); Victron's equivalent is the ESS assistant. User's own Notion DB tracks it as the "Simultaneous inverter+grid" column.
- Notion grid: Sol-Ark 15k-2p = "Verified yes" (+200A passthrough); EG4 18kPV & 12kPV = "Verified no" (18kPV fully switches to grid-bypass >12kW/50A, re-checks ~3min — per user's phone call to EG4 2025-12-02); Victron = "Verified no" (ESS unavailable in US); Tesla PW3/FranklinWH/Enphase/SolarEdge = "idk".
- HARDWARE CONFIRMED OWNED/BUILDING (user, this session): 2× MultiPlus-II 48/5000 120V, 3× SmartSolar 250/70, Cerbo GX (+VM-3P75CT, Lynx, 200A external-ATS topology per Notion mermaid).
- Victron ESS in US: no North-America grid code exists; enabling requires installer password + grid code "Other"; will not pass inspection; no US PoCo known to have approved it (as of 2025-04→2026-02).
- Victron has base UL1741 listings on some models (needed for building code / non-interactive install) but NOT UL1741SA/SB (grid-support functions per IEEE 1547), which most US grid operators require for interconnection. "You can still connect the units to the grid without ESS assistant installed."
- ESS physically guarantees momentary backfeed (~1-2s bursts when large loads drop) — control loop + CT-measurement latency; mitigation (10Hz EM530 meter, CTs) reduces but cannot eliminate. Detectability depends on meter; smart meters detect it; consequences range nothing → disconnection.
- Dec-2025 datapoint: long-time US ESS runner (Victron community) removed ESS assistant ahead of utility smart-meter swap ("can detect even the smallest amount of backfeed").
- The "you don't need ESS" counter-claim = the *ignore-AC-input* workaround (Cerbo generator-start/stop or assistants toggling the input relay): time-multiplexed island/grid alternation, NOT blending. Pain points (silverlexg 2025-03): assistant changes need inverter power-cycle; relay hack mislabels grid as generator in metrics; ignoring AC = can't see grid-outage state; SOC-hold causes charge/discharge churn; US UL MultiPlus 2000 lacks aux inputs.
- Illinois: full-retail net metering sunset 2025-01-01 → "Smart Solar Billing" (supply-only export credit); legacy = energized before 2024-12-31 (user is NOT legacy). One-time DG "Smart Inverter" Rebate $300/kW + Storage Rebate $300/kWh. ComEd DER Interconnection Team = interconnect@comed.com / 630-576-8158 (user already has).
- Project context (Notion): Logan Square Chicago, ComEd, 200A service; 20.5kWh Eco-Worthy LiFePO4 (owned); ~19-21× CWT550 panels; loads incl. EV, homelab servers, future dual heat-pumps.
