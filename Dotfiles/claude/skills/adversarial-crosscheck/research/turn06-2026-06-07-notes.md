## Findings
- The claim IS supportable, but only with the same caveat-shape as the rest of the README: genuine + *plausible* contrary input broadens; overdone / role-played / solo input backfires or entrenches.
- [A-schwenk-1990] is correctly removable for THIS clause — it measured decision *quality/accuracy* and explicitly excluded process/breadth measures; it is not evidence for "explore more angles."
- Best replacement is [A-hirt-markman-1995]: it directly generalizes [A-lord-lepper-preston-1984] and shows considering an alternative *spontaneously broadens the considered set* (not mere averaging). Peer-reviewed, fully read → A.
- [A-mercier-sperber-2011] supports the *externalization* rationale (evaluate-others'-args >> solo reasoning; groups reason far better) AND the README's "solo wilted cross-check entrenches" caveat (sec 4.2.2 bolstering). Genuine-argumentation caveat: role-played/LLM dissent qualifying is untested.
- [B-shi-multipersona-2024] is the closest LLM-mechanism analogue and leans PRO (eye-tracking: more attention to opposing content; modest conviction drop) — but it's a preprint, n=40, controversial-topic info-seeking (adjacent construct), multi-persona not binary. The Semantic-Scholar snippet ("does not significantly increase attention to opposing views") UNDERSOLD it; the full read shows a significant increase. Grade-from-read mattered here.
- Boundary/backfire is real: [A-hirt-markman-1995] Study 3 (implausible alternatives fail to debias); Sanna, Schwarz & Stocker 2002 (generating *many* reasons backfires via ease-of-retrieval) — the latter only snippet-level, NOT full-read, so ungraded/unstamped (lead only).
- Net: user is not "straight-up wrong"; the honest version is a coverage/broadening claim with a plausibility/genuineness boundary, citing [A-hirt-markman-1995] (+ optionally [A-mercier-sperber-2011] for the externalization "why", and [B-shi-multipersona-2024] for the LLM-form, clearly flagged as preprint/adjacent).
